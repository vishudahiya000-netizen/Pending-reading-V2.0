Firebase setup checklist

  1. Firebase Console → Authentication → Sign-in method → enable Anonymous (no Gmail login).
  2. Firestore Database must be created in Production mode.
  3. Cloud Storage must be enabled if you want photos uploaded to the cloud. Check Firebase billing/plan before enabling; charges may apply.
  4. Add the secure Firestore and Storage rules supplied with this file's instructions before using real records.
  5. Open this app and press Sync now. The app attempts anonymous sign-in and syncs when Firebase rules/storage are configured. No Gmail login is shown.

Old records migration

The app attempts to copy the previous app's LocalForage key mbm_manager_starter_records_v1 into the signed-in account's local IndexedDB records, without deleting the original key. It also imports old localStorage records if present. Review the record count and export an Excel backup before proceeding.

Migration only finds data in the same browser/device where the old app stored it. It cannot recover records from another phone or from a browser whose site data was cleared. Keep the original backup Excel.

Conflict handling

This starter uses the latest updatedAt timestamp for a record ID. If you edit the same record on two devices while offline, review the final values after syncing. Do not treat this as a full audit log.
